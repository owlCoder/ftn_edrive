# ftn_edrive

Home of FTN materials — arhiva materijala, projekata i rešenih zadataka sa studija na
**FTN** (Fakultet tehničkih nauka), organizovano po semestrima.

## Struktura

| Folder | Sadržaj |
|---|---|
| [`semestar-3/`](semestar-3/) | LPRS1, OOP, Primenjeni algoritmi |
| [`semestar-4/`](semestar-4/) | Namenski računarski sistemi, OOT, Operativni sistemi |
| [`semestar-5/`](semestar-5/) | Elementi razvoja softvera, MSS, PRMIS, Programski prevodioci, Uvod u baze podataka |
| [`semestar-6/`](semestar-6/) | AUS, Inženjerstvo upotrebljivosti, ODP, Veb programiranje, Virtuelizacija procesa, Osnove informacione bezbednosti (e-shop projekat) |
| `semestar-6/_skripte/` | Skripte i predavanja |
| [`julia-algoritmi/`](julia-algoritmi/) | Uvod u algoritme — primeri u Julia jeziku |
| [`avl-stablo/`](avl-stablo/) | AVL / binarno stablo implementacija u C-u |
| [`ODP 2025/`](ODP%202025/) | Osnove distribuiranog programiranja — vežbe 2025 (React/Vite, validacija, klijent-server, auth, replikacija, nadzor) |

> Grane `odp3` i `odpp` hostuju [GitHub Pages](https://owlcoder.github.io/ftn_edrive/) i nisu deo ove strukture.
> Materijali su isključivo za ličnu/edukativnu upotrebu.
